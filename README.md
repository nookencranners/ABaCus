# ABaCus Platform

## Repository Structure
- `frontend/` — Web interface, account/profile views, and teacher dashboard
- `game-godot/` — Godot 4 math mini-games and adaptive difficulty logic
- `backend/` — Java application service (`app-service.jar`) and REST APIs
- `database/` — Oracle Database 21c DDL/DML scripts

## Branching & Contributions
- Create a feature branch from `main` (e.g., `feat/student-accessibility`)
- Open a Pull Request and get teammate review before merging into `main`
